# CV Suite (OpenCV + ImGui)

Aplicación de visión por computadora en C++.

## Funcionalidades
- Thresholding (Otsu vs Adaptive)
- Segmentación médica e industrial
- Detección de bordes (Canny)

## Tecnologías
- C++
- OpenCV
- ImGui
- GLFW
- CMake

## Ejecutar (macOS)
```bash
cmake -B build
cmake --build build
./build/bin/CVSuite
